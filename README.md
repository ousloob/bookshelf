A RESTful API built in Go that allows users to manage their personal book collections. This project serves as a reference implementation for idiomatic Go API development.

## **Features**

- User authentication and authorization
- CRUD operations for books in a user's collection
- Deployment in a cluster using KIND

## **Tech Stack**

- Golang
- Go-Chi framework
- PostgreSQL
- Goose
- JWT for authentication
